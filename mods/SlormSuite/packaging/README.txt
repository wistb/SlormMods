SlormSuite
A collection of mods for The Slormancer.

REQUIREMENTS
  The Slormancer on Steam (Windows, 64-bit)
  The Aurie mod loader, installed first. The easiest way is SlormAPI's
  installer: https://github.com/tsotsas/SlormAPI/releases
  Microsoft Visual C++ 2015-2022 Redistributable (x64). Most PCs already
  have it. If the mod does not load, install it from
  https://aka.ms/vs/17/release/vc_redist.x64.exe

INSTALL
  1. Back up your save: %LocalAppData%\The_Slormancer
  2. Open the game folder
     (Steam: right-click the game > Manage > Browse local files)
  3. Extract this zip into it, so SlormSuite.dll lands in
     mods\Aurie
  4. Start the game from Steam as usual

USE
  Press F7 to show or hide the SlormSuite window; the key can be changed
  on the Options tab. Each mod is turned on and set up on the Mods
  tab, or on a tab of its own. All of them start off.

UNINSTALL
  Delete mods\Aurie\SlormSuite.dll and SlormSuite-README.txt from the
  game folder; your settings are the other SlormSuite files in
  mods\Aurie. The game's own files are never changed.

FILES IN THIS ZIP
  mods\Aurie\SlormSuite.dll   the mod
  mods\licenses\                   license and source of the above

Created while playing: aurie.log, and in mods\Aurie the files
SlormSuite.txt (your settings), SlormSuite.layout.ini and the folders
SlormSuite.forge and SlormSuite.macros (lists and macros you saved).
